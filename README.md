# منصة التحقيقات المفتوحة: التحميل

برنامج سطح مكتب عربي للتحقيقات المفتوحة المصدر والتحقق من الأدلة. كل البيانات تبقى على جهاز المحقق.

**للتحميل:** افتح [أحدث إصدار](https://github.com/anasshabrah/osint-workbench-releases/releases/latest) وحمّل
`OSINTWorkbench-Setup-….exe` من قسم «Assets».

- Windows 10 أو 11 بنسخة 64-بت. لا يحتاج صلاحيات مدير النظام ولا تثبيت أي برنامج آخر.
- المثبّت غير موقّع رقمياً بعد: عند ظهور «Windows protected your PC» اضغط **More info** ثم **Run anyway**.
- بصمة SHA-256 لكل ملف مذكورة في صفحة الإصدار للتحقق من سلامة التحميل.
- هذه نسخة تجريبية: استخدمها مع مواد تجريبية أو عامة فقط.

هذا المستودع يحتوي ملفات التثبيت فقط، لا الكود المصدري.
